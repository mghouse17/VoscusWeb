HOW TO USE
==========

1. EXTRACT ALL FILES
   - Copy entire voscus-landing folder
   - Maintain directory structure
   - Keep relative imports intact

2. INSTALL DEPENDENCIES
   $ npm install

3. RUN LOCALLY
   $ npm run dev
   - Open http://localhost:3000
   - Click demo tabs to interact
   - Test on mobile/tablet

4. BUILD FOR PRODUCTION
   $ npm run build
   $ npm start

5. DEPLOY TO VERCEL
   - Push to GitHub
   - Connect to Vercel
   - Auto-deploys on push
   - Add custom domain in settings

CUSTOMIZATION QUICK TIPS
========================

UPDATE DEMO SCENARIOS
- Edit DemoData object in voscus-landing.jsx
- Change titles, actions, issues, timeline steps
- Add more scenarios if needed

CHANGE COLORS
- Edit tailwind.config.js color palette
- Or change Tailwind classes in component
- Both approaches work

UPDATE CONTENT
- Change navbar links, hero text, CTAs
- Modify feature descriptions
- Update use cases
- Edit footer

ADD YOUR LOGO

CONNECT BACKEND
